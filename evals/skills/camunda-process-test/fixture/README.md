# AI Agent Chat fixture

`ai-agent-chat-with-tools.bpmn` is pinned from
[`camunda/camunda-8-tutorials@7f11075`](https://github.com/camunda/camunda-8-tutorials/blob/7f110759cfe25f5a96a064f4d183d4022bc328c4/solutions/ai-agent-chat-with-tools/ai-agent-chat-with-tools.bpmn).

The fixture preserves the AI Agent ad-hoc subprocess, its four connector tools,
the user-feedback retry loop, and the completed business outcome used by the
three-layer outcome eval. The eval copies it unchanged into the generated
harness.
